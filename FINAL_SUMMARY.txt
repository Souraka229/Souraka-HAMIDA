🚨 TROUBLESHOOTING RAPIDE
═══════════════════════════════════════════════════════════════════════════

Build échoue?
  → npm run build en local
  → Vérifier tsconfig.json
  → Nettoyer: rm -rf .next node_modules

500 Error en production?
  → Vérifier les env vars dans Vercel Dashboard
  → Voir les logs: vercel logs --tail
  → Tester localement: npm run dev

Rate limit exceeded?
  → Implémenter le caching (voir INTEGRATION_EXAMPLES.md)
  → Augmenter la limite: checkRateLimit(userId, 200, 3600)

API Key not found?
  → Vérifier .env.local
  → Vérifier Vercel Dashboard → Environment Variables
  → Redémarrer: npm run dev
